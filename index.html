One plugin for server chat

Manage your server chat from one place.

CoreChatX brings together public chat, channels, private messages, mentions, moderation, player settings, ChatItems, Discord, and Telegram. Use it on one Paper server or across a Velocity network.

Choose your setup Explore features
  • Java 21
  • Paper 1.21.11
  • Optional Velocity support
  • Settings saved in YAML files

What CoreChatX includes

Everything you need to manage player communication.

Set up how messages look, where they are sent, what players can control, and which tools are available to staff.

Chat features

Messages, channels, and player names

Control how players talk to each other and how messages appear.

Chat, channels, and formatting

Customize chat formats, rank prefixes, placeholders, local chat, and network-wide channels.

Private messages and player names

Private messages, replies, ignore controls, player preferences, nicknames, and real-name lookup.

Mentions and interactive content

Player mentions, custom pings, clickable keywords, item previews, and optional chat bubbles.

Server management

Moderation, player settings, and integrations

Give players useful controls and staff the tools they need.

Moderation and privacy

Mutes, chat clearing, anti-repeat, anti-caps, filtering, staff bypasses, and configurable ignore behavior.

Player settings

Players can manage notifications, private messages, language, bubbles, hidden channels, and privacy.

Optional Discord and Telegram connections

Send selected Minecraft channels to Discord or Telegram and receive messages back in game.

Two operating modes

Start with one Paper server. Add Velocity when the network needs it.

Area Standalone Paper Paper + Velocity
Files to install Paper jar on the server Paper jar on every server and Velocity jar on the proxy
Where shared settings are saved On the Paper server On Velocity, separated by server group
Channels and PMs Local to the Paper server Network channels and private messages can cross Paper servers in the same group
Discord Configured on Paper Configured on Velocity for chat, account linking, and Discord role requirements
Telegram Configured on Paper Configured on the Paper server that sends the message

Latest update

2026.2.6

More control for players and more reliable network settings.

  • /hidechannel <channel> [minutes] and /unhidechannel <channel> add permanent or timed personal channel visibility.
  • If a linked player loses a required Discord role, CoreChatX now disconnects them and blocks access until the role is restored.
  • Settings, replies, Discord unlinking, and Discord player lists now stay correct after reloads and simultaneous updates.
