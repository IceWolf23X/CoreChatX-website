Purpose:#

  • mention notification toggles
  • custom ping definitions
  • permission rules for custom pings

Current bundled default:#

Validation note:#

  • use-permission and receive-permission are validated
  • malformed dynamic permission nodes are warned and individually disabled
  • Minecraft senders require the configured Bukkit use-permission; leaving it blank makes activation unrestricted for Minecraft senders
  • Discord senders require a configured matching discord-roles entry; an empty list blocks Discord activation even when use-permission is blank
  • Telegram and generic remote senders can activate only pings with a blank use-permission; remote metadata cannot grant Bukkit permissions or Discord roles
  • receive-permission, channel mention rules, recipient selection, and bypass-toggle still apply after activation

Network note:#

  • when a custom ping is activated in a NETWORK channel, CoreChatX forwards the activated ping metadata with the message so remote backends can deliver the matching actionbar/sound notification locally
