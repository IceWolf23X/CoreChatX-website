Private messaging is part of the same communication system as public chat.

Included tools:#

  • direct messages
  • reply command
  • social spy
  • ignore controls
  • PM toggle
  • delivery feedback
  • cross-server private messages

The result is a PM system that understands the rest of the plugin: privacy, moderation, network routing, formatting, and player settings all live in the same ecosystem.

Cross-server PM requests use bounded correlation and reject overlapping work instead of accumulating an unbounded queue. A forwarded PM consumes its configured cooldown once accepted for routing, even if the remote destination later rejects it or the request times out. A timeout does not prove that the remote operation was cancelled.
