CoreChatX can show recent chat messages above player heads.

Bubble features include:#

  • player toggle
  • channel rules
  • world rules
  • sneaking checks
  • invisibility checks
  • configurable duration
  • message wrapping
  • stacked recent messages
  • distance-based visibility
  • cleanup on quit, reload, and shutdown

Chat bubbles use the already processed message. Channels with STAFF scope or a non-empty receive permission never create bubbles, even when explicitly included in the bubble allowlist; allow-chat-bubbles: false and disabled-channel filters remain authoritative.

Public-channel bubbles are globally tracked entities with their own view distance. They do not enforce per-viewer ignore or hidden-channel rules, or a chat radius smaller than the bubble view range. Disable bubbles for a channel when those audience restrictions must also apply to overhead text.

On a network, bubbles stay local to the server where the sender is physically playing. That keeps the feature useful without pretending an overhead bubble can float across servers.
