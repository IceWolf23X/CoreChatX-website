Complete feature overview

All your server communication tools in one plugin.

CoreChatX combines chat, channels, private messages, player settings, moderation, interactive content, and optional Discord or Telegram connections. The same features work on one Paper server or across a Velocity network.

Feature overview

Features work together without extra setup between plugins.

A channel can have its own format, permissions, mentions, item previews, and Discord or Telegram connection. Player settings such as ignores and notifications apply wherever they are relevant, including across connected Paper servers.

Chat and nicknames

Customize chat without giving players unsafe formatting access.

Use MiniMessage templates to control how chat looks. Players can use only the colors and styles you explicitly allow through permissions; they cannot insert arbitrary MiniMessage tags.

Flexible chat presentation

Create default, rank-specific, and channel-specific formats with LuckPerms prefixes and PlaceholderAPI values. You can also customize join, quit, first-join, broadcast, private-message, and moderation messages.

PlaceholderAPI integration

Show player data, economy values, worlds, progress, or server statistics in formats. Install the expansion for each placeholder you use on every Paper server that displays it.

Persistent nicknames

/nick changes the name shown in chat without changing the player's real Minecraft account. You can limit nickname length and characters and prevent duplicate or misleading names.

Granular nickname formatting

Use separate permissions for standard colors, hex colors, gradients, and styles. Staff can use /realname to find the account behind a nickname, and linked Discord nicknames can be updated automatically.

Channels

Create a separate chat for every purpose.

Set up global, local, staff, network-wide, rank-based, or custom channels. Each channel controls who can send and receive, how messages look, which interactive features work, and whether messages are forwarded to Discord or Telegram.

ScopeDeliveryTypical use
NETWORKAcross Paper servers in the same Velocity group; local on a standalone serverGlobal or staff network chat
SERVERCurrent Paper server onlyServer-specific communication
LOCAL_RADIUSNearby recipients in the configured world radiusLocal or roleplay chat
  • Send and receive permissions are independent.
  • Channel commands such as /g can switch the active channel or send one message without switching.
  • Channels independently enable mentions, ChatItems, chat bubbles, Discord export, and Telegram export.
  • Public-chat ignore settings can use the global choice or a different choice for one channel.
  • /hidechannel <channel> [minutes] supports timed or permanent personal hiding; /unhidechannel restores access.

A hidden channel cannot be used or seen by that player until the timer ends or they unhide it. On a Velocity network, this choice follows the player between connected Paper servers.

Private messages

Give players private chat with useful privacy controls.

  • /msg with /tell, /whisper, and /w aliases.
  • /reply and /r; the previous recipient is cleared when a player leaves.
  • Cross-server delivery between Paper servers in the same Velocity group.
  • Players can enable or disable incoming private messages with /pmtoggle.
  • /ignore, /unignore, and /ignorelist for personal privacy.
  • Optional cooldowns, clear delivery messages, moderation checks, and staff bypass permissions.
  • /socialspy and /spy for permitted staff.

Private messages automatically use the same nicknames, ignores, mutes, player settings, and network groups as the rest of CoreChatX.

Interactive features

Make chat more useful with mentions, links, items, and bubbles.

Mentions and custom pings

Mention a player by name or use custom triggers to play a sound and show an actionbar notification. Mentions can also work across Paper servers in the same Velocity group.

Interactive keywords

Turn text such as [rules], [store], or [vote] into a clickable link, command, suggestion, hover message, or copy button. You can limit each keyword by permission or channel.

ChatItem previews

Players can share a held item, shulker, armor, hotbar, inventory, or ender chest. CoreChatX saves a temporary copy when the message is sent, so the preview stays accurate even if the player's inventory changes later.

Discord ChatItem images

Discord can show shared items and inventories as images, including names, lore, enchantments, effects, trims, banners, books, fireworks, durability, and supported resource-pack textures. Inventory previews can include buttons for inspecting individual items.

Chat bubbles

Optional chat bubbles appear above players and can control line wrapping, duration, viewing distance, worlds, sneaking, invisibility, and how recent messages are stacked. Bubbles stay on the Paper server where the player is located.

Every interactive feature can be enabled separately and follows its permissions, allowed channels, ignore rules, and player notification settings.

Player settings

Let players choose how they use chat.

/chatsettings and /ccxsettings open the settings menu. Players can also use individual commands for common choices.

Saved preferences

Players can control ping sounds, actionbar notifications, private-message availability, chat bubbles, active channel, hidden channels, social spy where permitted, and mention notifications.

Ignore settings

Ignoring can remain PM-only, suppress public mention and custom-ping notifications, or hide public messages. Individual channels can inherit or override the global public-chat mode.

Locale support

Players can choose a language when you provide a matching language file. Any missing text automatically uses the main message file.

Works across a network

On one Paper server, preferences are saved locally. On a Velocity network, the same settings follow the player between Paper servers in the same group.

Moderation and privacy

Give staff the tools to keep chat under control.

  • /mute and /unmute for individual players.
  • /mutechat to temporarily stop public chat.
  • /clearchat for server-side chat clearing.
  • Anti-repeat, optional anti-caps, and a censoring word filter.
  • Configurable staff bypass permissions.
  • Public-chat ignore modes: off, notifications only, or hide message.
  • Per-channel ignore-mode overrides without changing PM blocking.

These rules apply directly to CoreChatX chat, channels, and private messages, including communication across connected Paper servers.

Discord and Telegram

Connect selected Minecraft channels to Discord or Telegram.

Both integrations are disabled by default. You choose which Minecraft channels can send messages outside the game and where incoming messages should appear.

Discord chat and events

Send messages in both directions for selected channels. You can also show joins, quits, first joins, deaths, advancements, proxy status, and Paper server status.

Account linking and Discord role requirements

Players can link their Minecraft and Discord accounts. You may require a linked account or an allowed Discord role to join; players who lose the required role are disconnected until access is restored.

Discord utilities

Configure player lists, slash commands, channel descriptions, online counts, status messages, console commands, live console output, and ChatItem images separately.

Telegram chat connection

Send messages in both directions through normal Telegram chats or forum topics by adding their chat and topic IDs.

Safe defaults

CoreChatX limits message sizes, prevents unwanted Discord mentions from Minecraft, checks permissions, and stops integration tasks cleanly during reloads and shutdowns.

Velocity networks

Keep chat and player settings consistent across servers.

Divide your Velocity network into CoreChatX groups. Paper servers in the same group share communication features and player settings, while separate groups remain independent.

  • Network-wide channels and cross-server private messages.
  • Player directory, name suggestions, TAB entries where available, mentions, and pings.
  • Shared settings, nicknames, hidden channels, ignore lists, mutes, and reply targets.
  • Clickable keywords and ChatItem previews across Paper servers.
  • Group-specific joins, quits, first joins, player lists, status messages, and Discord channel descriptions.
  • Discord account linking and role requirements managed from Velocity.
  • Discord and Telegram messages sent once without duplicates from every Paper server.

When a player unlinks Discord, the change is kept even if one Paper server is offline and reconnects later. CoreChatX also rejects invalid or oversized network messages.

Server management

Clear tools for setup, reloads, and everyday administration.

CoreChatX provides clear startup information, configuration checks, safe data saving, and commands for both players and staff.

Clear startup information

The startup message shows the CoreChatX version and whether the Paper or Velocity jar is running. Permissions use corechatx.*, and the default network group is corechatx:main.

Configuration and data safety

CoreChatX checks important settings, recreates missing configuration files, saves YAML safely, and keeps each Velocity group's data separate.

Safe reloads

Most Paper settings can be reloaded without restarting. CoreChatX also clears old reply targets when players leave and restarts enabled Discord or Telegram connections cleanly.

Commands for players and staff

Commands cover plugin status and reload, player settings, language, private messages, social spy, privacy, channels, pings, nicknames, Discord linking, broadcasts, moderation, chat clearing, and ChatItem cache management.
