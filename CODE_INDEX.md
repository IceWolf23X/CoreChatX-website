# CoreChatX Website Code Index

## Public pages

- `index.html` — Product overview, 2026.3.1 advancement/death/PremiumVanish release summary, setup and changelog links, Paper and Velocity bStats data, and related CoreX plugins.
- `tags.html` — Static feature tags and 24 sourced plugin/module comparisons, a feature replacement map, four partial YAML examples, complementary-plugin guidance, replacement FAQs, and switching/data-import boundaries; linked from shared navigation, Features, Documentation, and the sitemap.
- `features.html` — Chat, channel-persistence preferences, private messages, moderation, integrations, PremiumVanish connection privacy, YAML/MySQL storage, Velocity support, and optional advancement/death-event network features.
- `installation.html` — Paper/Velocity and version-specific Java requirements, optional dependency placement including PremiumVanish platform scope, 2026.3.1 upgrade path, coordinated protocol-29 deployment, V004 MySQL schema boundary, YAML/MySQL migration and backup ownership, optional advancement setup, integrations, and validation checks.
- `configuration.html` — Paper and Velocity configuration and bundled examples, PremiumVanish hook behavior and lifecycle, storage maintenance grammar, channel persistence, optional advancement/death-event network features, Discord admission and `{link_command}` message templates, commands on both platforms, runtime-data fields and ordering markers, safe configuration regeneration, strict YAML load failures, proactive proxy join reads with retained mute enforcement, optional Modrinth stable/preview notices for OP players, permissions, and troubleshooting. Bundled examples match the 2026.3.1 release; existing section anchors are retained.
- `advancement-sync.html` — Dedicated, responsive setup guide for optional full advancement synchronization: backups, Velocity group pins and authenticated endpoint, Paper backend settings, verification, operation failures, V004 and snapshot-format boundaries.
- `docs.html` — Documentation entry point, migration and advancement-setup cards, storage ownership, and release-notes links.
- `changelog.html` — Release archive with 27 versions from 2026.1.0 through 2026.3.1 in descending version order, including the latest advancement, death-relay, and PremiumVanish notes, an expandable version index, and historical Markdown imported from local release folders or Modrinth for the earliest four versions.
- `migration.html` — Backup-first selector for two complete migration guides; preserves incoming legacy anchors and links to platform-specific recovery.
- `migration-paper.html` — Independent 15-step standalone Paper YAML-to-MySQL walkthrough: backup, connection, per-command output, run/token examples, activation, saved-data checks and reopening; optional Paper rollback/recovery follows completion.
- `migration-velocity.html` — Independent 15-step proxy YAML-to-MySQL walkthrough, including all-group confirmations and explicit Paper/Velocity startup order; optional proxy rollback/recovery follows completion.
- `faq.html` — Common setup and behavior questions, including PremiumVanish announcement scope, configurable staff bypass for private-message privacy, and proactive proxy moderation loading.
