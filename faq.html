Frequently asked questions

Clear answers to common questions.

These answers apply to CoreChatX 2026.2.6. Open the configuration reference when you need exact file names, settings, commands, or permissions.

Platform and installation

Install the correct file on each server.

What is CoreChatX?

CoreChatX is a chat plugin for Minecraft servers. It combines public chat, channels, private messages, replies, mentions, pings, ChatItems, moderation, player settings, Discord, Telegram, and optional Velocity network support.

What do I need to run CoreChatX?

You need Java 21 and Paper 1.21.11. Velocity is optional and is needed only when CoreChatX must connect multiple Paper servers.

Do I need Velocity?

No. One Paper server can use CoreChatX on its own. Add Velocity only if chat channels, private messages, player settings, or ChatItem previews must work across multiple Paper servers.

Which jar goes where?

Place corechatx-paper-<version>.jar in the plugins/ folder of every Paper server that uses CoreChatX. Place corechatx-velocity-<version>.jar in Velocity's plugins/ folder.

Why do deployment changes require a restart?

The mode, server ID, and network group decide how each server connects to CoreChatX, so they are read when the server starts. Restart after changing them. For normal Paper changes such as messages, channels, moderation, and integrations, use /corechatx reload.

Chat and player controls

Choose who can talk, where messages go, and what players can change.

Does CoreChatX support MiniMessage and PlaceholderAPI?

Yes. You can use MiniMessage and PlaceholderAPI in formats created by the server owner. Players cannot put arbitrary PlaceholderAPI values in their own messages. Install PlaceholderAPI and the expansions you use on every Paper server that displays those values.

What do the NETWORK, SERVER, and LOCAL_RADIUS channel types mean?

NETWORK sends chat across Paper servers in the same Velocity group. SERVER keeps chat on the current Paper server. LOCAL_RADIUS sends it only to nearby players in the same world. Without Velocity, NETWORK stays on the local server.

Can players hide a channel without losing permission?

Yes. /hidechannel <channel> [minutes] hides a channel permanently or for a chosen number of minutes. The player cannot send or receive messages in that channel until the timer ends or they use /unhidechannel. On a Velocity network, the choice follows the player between Paper servers.

What does ignoring another player affect?

Ignore always blocks private messages. Public chat can remain unaffected, suppress only mention and custom-ping notifications, or hide the ignored sender’s messages. Each channel may inherit or override the global public-chat mode.

Do nicknames replace the real Minecraft identity?

No. A nickname changes only the name shown in chat. Permissions and staff commands still use the player's real Minecraft account. Use /realname to find the account behind a nickname.

Do private messages work across servers?

Yes, when both players are in Paper servers connected to the same CoreChatX Velocity group. Players in a different group cannot be reached through that private-message route.

ChatItems and notifications

Share useful information directly in chat.

What can a ChatItem preview contain?

Players can share a held item, shulker contents, armor, hotbar, inventory, or ender chest. CoreChatX saves a temporary copy when the message is sent, so later inventory changes do not alter the preview.

Do ChatItems work across different Paper servers?

Yes. When a player on another Paper server clicks the preview, CoreChatX retrieves the saved item data from the server where it was shared. If the preview has expired or is unavailable, the player sees the normal expired-preview message.

Can Discord display ChatItem images?

Yes. Enable Discord ChatItem images and allow both ChatItems and Discord export for that Minecraft channel. Inventories can include buttons for viewing individual items. If Discord cannot create the image, the in-game preview still works.

Do chat bubbles cross the network?

No. A bubble is visible only on the Paper server where the sender is playing. Its visibility still follows the configured channel, world, distance, duration, and player settings.

Discord and Telegram

Connect only the services you want to use.

Where should the Discord bot run?

For one Paper server, configure the bot on Paper. For a Velocity network, configure the main bot on Velocity for chat, account linking, Discord role requirements, and network-wide features. A Paper server may use a separate bot token only for its local console connection.

Which Discord intents are required?

Enable Message Content if Discord messages must appear in Minecraft. Enable Server Members Intent if players must have a Discord role to join or if CoreChatX must react when that role is removed.

What happens when a linked player loses the final allowed Discord role?

CoreChatX disconnects the affected online player and blocks reconnection until the configured requirement is satisfied again. This applies to standalone Paper and Velocity when role admission is configured correctly.

How does Telegram receive messages?

CoreChatX checks the Telegram Bot API for new messages and sends replies through the same API. You only need a bot token and the chat or topic IDs used by your routes.

Can Telegram route forum topics?

Yes. Add the forum topic's message-thread-id to the route. For incoming messages, use both the chat ID and topic ID.

Saved data and troubleshooting

Protect player data and check the basic settings first.

Can CoreChatX save data in SQL?

No. CoreChatX currently saves its data in YAML files. The SQL settings are reserved for future use and do not move data to a database.

Which data should I back up?

For one Paper server, back up the complete plugins/CoreChatX/ folder. For a Velocity network, also back up plugins/corechatx/data/groups/, where shared player settings and moderation data are saved.

Why is network chat not crossing servers?

Check that every Paper server uses PROXY mode, has a unique server ID, enables network features, and uses the same network group as Velocity. The chat channel must also use scope: NETWORK.

Why did a configuration file regenerate?

CoreChatX recreates a missing configuration file with default settings when it starts. Be careful: files containing player settings, mutes, ignores, nicknames, or linked accounts are live data. Deleting those files deletes that saved information.
